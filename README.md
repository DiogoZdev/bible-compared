# 📖 Bíblia Comparativa

Uma ferramenta de estudo bíblico moderna, desenvolvida com **Angular** e **Tailwind CSS**, que permite a comparação paralela de diferentes traduções em múltiplos idiomas, incluindo suporte a idiomas RTL (como Hebraico).

---

## 🚀 Funcionalidades

* **Comparação Lado a Lado:** Visualize duas versões simultaneamente para análise exegética.
* **Suporte Multilíngue:** Filtros inteligentes para versões em Português, Espanhol, Latim, Grego, Alemão e Tailandês.
* **Sincronização de Foco:** Clique em um versículo para centralizar automaticamente ambas as colunas no mesmo ponto de estudo.
* **Suporte RTL (Right-to-Left):** Layout inteligente que se adapta automaticamente para idiomas como o Hebraico (`heb`).

## 🛠️ Tecnologias Utilizadas

* **Framework:** [Angular](https://angular.io/) (v17+)
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
* **API:** Integração com APIs de textos bíblicos [Hello AO](https://bible.helloao.org/docs/)


## 💻 Como rodar o projeto

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/seu-usuario/biblia-comparativa.git](https://github.com/seu-usuario/biblia-comparativa.git)
    ```
2.  **Instale as dependências:**
    ```bash
    npm install
    ```
3.  **Inicie o servidor de desenvolvimento:**
    ```bash
    ng serve
    ```
4.  Acesse `http://localhost:4200` no seu navegador.
