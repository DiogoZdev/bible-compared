# 📖 Bible Compared

A modern Bible study tool built with **Angular** and **Tailwind CSS** that enables side-by-side comparison of different translations across multiple languages, including support for RTL languages (such as Hebrew).

---

## 🚀 Features

* **Side-by-Side Comparison:** View two versions simultaneously for exegetical analysis.
* **Multilingual Support:** Smart filters for versions in Portuguese, Spanish, Latin, Greek, German, and Thai.
* **Focus Synchronization:** Click a verse to automatically center both columns on the same study passage.
* **RTL (Right-to-Left) Support:** Smart layout that automatically adapts to languages such as Hebrew (`heb`).

## 🛠️ Technologies Used

* **Framework:** [Angular](https://angular.io/) (v22)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **API:** Integration with Bible text APIs [Hello AO](https://bible.helloao.org/docs/)


## 💻 How to run the project

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/diogozdev/biblia-comparativa.git](https://github.com/diogozdev/biblia-comparativa.git)
    ```
2.  **Install the dependencies:**
    ```bash
    npm install
    ```
3.  **Start the development server:**
    ```bash
    ng serve
    ```
4.  Open `http://localhost:4200` in your browser.
